OpenEUV renderer benchmark

This benchmark uses original synthetic concept geometry: 2,048 instanced triangles. It is a renderer comparison harness, not an EUV simulation. WebGL remains the atlas baseline; WebGPU is measured only when the browser exposes navigator.gpu.

Measurements are browser/driver/device-specific. Do not adopt WebGPU from one run. Compare multiple reproducible runs on defined hardware classes.
